# Лабораторная работа #15
Задание ЛР

Оценка 3: 
1) Программа получает имя файла через аргументы командной 
строки: ./program staff.csv. 
2) Считать файл staff.csv. Каждая строка имеет вид: Elon 
Musk;5001;Level_A. Можно сгенерить нейронкой. 
3) Использовать fgets() для чтения строки и strtok() (или sscanf) 
для разделения полей по символу “;”. 
4) Вывод в консоль отформатированной таблицы со всеми 
сотрудниками. 

Оценка 4: 
5) Сохранить массив полученных структур в файл database.dat, 
используя fwrite(). 
6) Написать функцию поиска, которая открывает database.dat, 
считывает его через fread() и запрашивает у пользователя ID. 
7) Если сотрудник найден — вывести его данные на экран. Если 
нет — выдать ошибку. 

Оценка 5: 
8) Реализовать функцию compress(), которая читает бинарный 
файл database.dat и записывает сжатый файл database.rle. 
9) Находить последовательности одинаковых байт и записывать 
их как [count][value]. 
10) Реализовать функцию decompress(), восстанавливающую 
исходный файл из .rle. 
11) Вывести в консоль отчет:  
«Размер до: XX Кб, Размер после: YY Кб. Сжатие: ZZ%».
