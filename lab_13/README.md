# Лабораторная работа #13
Задание ЛР

Оценка 3: 
Сначала реализуем все в одном .c файле: 
1) Взять код из предыдущей практической работы и разбить его по 
каталогам: 
• src/ - все файлы исходного кода (.c) 
• include/ - все заголовочные файлы (.h) 
2) Написать Makefile в корне проекта для автоматизации сборки 
3) В Makefile реализовать сборку и линковку статической или 
динамической библиотеки (на ваш выбор) 
4) Обязательно наличие целей: 
• all – полная сборка проекта 
• clean – удаление всех скомпилированных файлов (.o, .a, .so и 
исполняемого файла) 

Оценка 4:

5) Создать CMakeLists.txt в корне проекта 
6) Описать сборку проекта через CMake в CMakeLists.txt 
7) Добавить возможность выбора типа библиотеки при конфигурации. 
Использовать опцию -D
