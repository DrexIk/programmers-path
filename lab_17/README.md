## Лабораторная работа #17

**Цель работы:** Покрыть модульными (unit) тестами исходный код с использованием специализированного фреймворка автоматизации тестирования и предоставить отформатированные результаты выполнения тестов.

### Выполненные шаги:
1. **Объект тестирования:** Для написания unit-тестов был взят и проанализирован сторонний программный код на языке C.
2. **Инструменты тестирования:** В качестве тестового фреймворка выбран специализированный фреймворк **cmocka**.
3. **Разработка тестов:** Реализованы unit-тесты, проверяющие корректность работы ключевых функций, включая валидацию входных данных, диапазонов значений и обработку граничных (крайних) случаев.
4. **Запуск и форматирование:** Произведен сбор данных и вывод результатов тестирования на экран в структурированном и отформатированном виде с помощью встроенных средств логирования фреймворка.
