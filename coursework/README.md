# РГР: Частотный анализ текста

## Задание

Разработать программу, производящую частотный анализ слов в исходном тексте. На вход программы подаётся два файла. Первый файл содержит текст, подлежащий анализу. Второй файл необходимо создать и записать в него все слова, встретившиеся в тексте, с указанием частоты их появления. Программа должна провести сортировку слов по частоте встречаемости в порядке убывания. Словом считается последовательность букв (кириллица или латиница), цифры и знаки препинания игнорируются.

---

## Что было сделано в проекте

1. **Ядро алгоритма (`analyzer.h`)**: Реализована функция чтения конфигурационного файла (`read_config`) и функция посимвольного анализа текста (`process_text`) с поддержкой широких символов (`wchar_t`) для корректной обработки кириллицы (UTF-8) в Linux.
2. **Динамическая память**: Хранение уникальных слов организовано через массив структур, динамически расширяемый в памяти с помощью функции `realloc` по мере обнаружения новых слов.
3. **Файловый ввод/вывод (`main.c`)**: Программа полностью автоматизирована и считывает пути к файлам из конфигурационного файла параметров в формате `KEY=VALUE`, а результаты сортировки сохраняет в файл на диске.
4. **Unit-тесты (`test_main.c`)**: С помощью профессионального криптографического фреймворка `CMocka` написаны изолированные автоматические тесты для проверки корректности работы функций ядра анализатора.
5. **Автоматизация сборки (`CMakeLists.txt`)**: Настроен конфигурационный файл CMake для раздельной компиляции основного приложения (`analyzer_prog`) и исполняемого файла тестирования (`run_unit_tests`).

---

## Структура проекта

*   `analyzer.h` — Ядро программы с функциями парсинга конфигурации и анализа частоты слов.
*   `main.c` — Главная программа (инициализация локали, запуск анализа, сортировка пузырьком и запись результатов).
*   `test_main.c` — Модульные юнит-тесты на фреймворке CMocka.
*   `config.txt` — Файл конфигурации с входными параметрами.
*   `input.txt` — Входной текстовый файл для проведения анализа.
*   `CMakeLists.txt` — Скрипт автоматической сборки для CMake.

## Инструкция по сборке и запуску

### Предустановка зависимостей (для Linux / Ubuntu)
Перед сборкой тестов убедитесь, что в системе установлена библиотека CMocka:
```bash
sudo apt-get update && sudo apt-get install -y libcmocka-dev
```

### 1. Подготовка входных данных
Перед запусками убедитесь, что в корне проекта создан файл `config.txt` с параметрами. Пример содержимого:
```text
INPUT_FILE=input.txt
OUTPUT_FILE=output.txt
```

### 2. Сборка проекта через CMake
Сборка выполняется стандартным для Linux способом:
```bash
cmake .
cmake --build .
```

### 3. Запуск тестов
Чтобы проверить правильность работы функций ядра алгоритма, запустите скомпилированные тесты CMocka:
```bash
./run_unit_tests
```

### 4. Запуск основной программы
Для проведения частотного анализа текста выполните команду:
```bash
./analyzer_prog
```

### 5. Результаты работы
После запуска программы в корневой директории автоматически создается (или обновляется) файл с отсортированными по убыванию результатами:
*   `output.txt` — Результат частотного анализа текста.
